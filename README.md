## 🎯 Что такое ПОЛ?

ПОЛ — универсальный AI-агент для обучения, который адаптируется к любой отрасли через модульные промпты.

**Три режима:**
- 📱 **Standalone** (Бесплатно) — чат в Claude.ai, без установки
- 🟡 **Industry Packs** (Бесплатно) — пакеты (фармацевтика, здравоохранение, образование)
- 🖥️ **Enterprise** (Платно €15–20/мес) — VPS с VAULT памятью, n8n автоматизация

---

## ✨ Возможности

- Микронавчание (макс 30 мин сессии)
- Геймификация (значки, баллы, рейтинги)
- Коучинг по эмоциональному интеллекту
- Генерация интерактивного контента
- Многоязычность (русский, украинский, английский, немецкий)

---

## 🚀 Быстрый старт

1. Скопируй промпт из `pol-base-prompt.txt`
2. Вставь в [Claude.ai](https://claude.ai)
3. Выбери отрасль или задай вопрос
4. Получай модули обучения, тесты, коучинг
